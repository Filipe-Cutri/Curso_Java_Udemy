Bem-vindo ao Sistema de Gerenciamento

Este é um sistema completo de gerenciamento desenvolvido com Spring Boot, com interface responsiva otimizada para smartphones e desktops.

Funcionalidades disponíveis:

  • ✅ Gerenciamento completo de usuários
  • ✅ Catálogo de produtos com imagens
  • ✅ Sistema de pedidos e controle de status
  • ✅ Organização por categorias
  • ✅ Interface responsiva para smartphones
  • ✅ API REST completa
